الويب بمفهومي

الويب مجموعة من الصفحات والمواقع المترابطة. أستخدم المتصفح لطلب صفحة من الخادم، ثم يعرض المتصفح محتواها لي.

كيف تظهر صفحة الموقع؟

  1. أكتب عنوان الموقع في المتصفح.
  2. يطلب المتصفح ملفات الصفحة من الخادم.
  3. يرسل الخادم ملفات الصفحة إلى المتصفح.
  4. يقرأ المتصفح الملفات ويعرض الصفحة.

HTML: هيكل الصفحة

أستخدم HTML لتحديد محتوى الصفحة وتنظيمه، مثل العناوين والفقرات والقوائم.

مثال على الكود

<h4>الويب ملوك المجالات!</h4>

CSS: ألوان الصفحة وتنسيقها

أستخدم CSS للتحكم في ألوان العناصر وخطوطها والمسافات بينها.

مثال على الكود

.pink-example {
    color: #b84482;
}

JavaScript: التفاعل مع الصفحة

أستخدم JavaScript لجعل الصفحة تستجيب لتفاعل الزائر.

أهلًا بك في مساحتي!

الكود الذي يغيّر الرسالة

button.addEventListener("click", function () {
    message.textContent = "أنا لميس، وهذه أول تجربة تفاعلية لي! 🌸";
    message.style.color = "#b84482";
});

الواجهة الأمامية والجزء الخلفي

Frontend: ما أراه وأتفاعل معه

في المتجر الإلكتروني، تشمل الواجهة الأمامية صور المنتجات والأسعار وزر الإضافة إلى السلة.

Backend: ما يحدث على الخادم

عندما أؤكد الطلب، يتحقق الجزء الخلفي من توفر المنتجات ويسجل الطلب في قاعدة البيانات.
