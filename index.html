التالي: الويب بمفهومي ↓

الويب بمفهومي

الويب مجموعة من الصفحات والمواقع المترابطة. أستخدم المتصفح لطلب صفحة من الخادم، ثم يعرض المتصفح محتواها لي.

كيف تظهر صفحة الموقع؟

  1. أكتب عنوان الموقع في المتصفح.
  2. يطلب المتصفح ملفات الصفحة من الخادم.
  3. يرسل الخادم ملفات الصفحة إلى المتصفح.
  4. يقرأ المتصفح الملفات ويعرض الصفحة.
التالي: اكتشفي HTML ↓

HTML: هيكل الصفحة

أستخدم HTML لتنظيم محتوى الصفحة، مثل العناوين والفقرات والقوائم والروابط.

مثال على الكود

<a href="https://mayash67.github.io/my-web-playground/"
   target="_blank" rel="noopener">
    افتحي مساحتي في الويب ↗
</a>

جرّبي الرابط

الخاصية href تحدد وجهة الرابط. الرابط التالي يفتح موقعي في تبويب جديد.

CSS: ألوان الصفحة وتنسيقها

أستخدم CSS للتحكم في الألوان والخطوط والمسافات. في هذه التجربة تحدد CSS الشكل، وتستخدم الأزرار JavaScript لتفعيل التنسيق وإلغائه.

مثال على الكود

#style-demo.is-pink {
    color: #b84482;
}

#style-demo.is-large {
    font-size: 28px;
}

جرّبي التنسيق بنفسك

اضغطي مرة للتغيير، ومرة أخرى للعودة.

الفن والكود يجتمعان في مساحتي!

التالي: جرّبي JavaScript ↓

JavaScript: التفاعل مع الصفحة

أستخدم JavaScript للاستجابة لتفاعل الزائر. هذا العدّاد يحفظ عدد الضغطات ويعرضه مباشرةً.

جرّبي العدّاد

عدد الضغطات: 0

الكود الذي يزيد العدّاد

let count = 0;

increaseButton.addEventListener("click", function () {
    count = count + 1;
    counterValue.textContent = count;
});

المتغير count يحتفظ بالعدد. كل ضغطة تزيده بواحد، وزر التصفير يعيده إلى صفر. تحديث الصفحة يبدأ التجربة من جديد.

الواجهة الأمامية والجزء الخلفي

Frontend: ما أراه وأتفاعل معه

في المتجر الإلكتروني، تشمل الواجهة الأمامية صور المنتجات والأسعار وزر الإضافة إلى السلة. وتجارب الأزرار في صفحتي تعمل داخل المتصفح.

Backend: ما يحدث على الخادم

عندما أؤكد الطلب، يتحقق الجزء الخلفي من توفر المنتجات ويسجل الطلب في قاعدة البيانات.
